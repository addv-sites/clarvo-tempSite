Conectar el formulario de /masterclass a Google Sheets

6 pasos, todo en tu propia cuenta de Google. Al final obtienes una URL que me pasas para conectar el formulario — no necesitas compartir contraseñas ni accesos de tu cuenta en ningún momento.

🔒
No compartas credenciales. Ni contraseña, ni verificación en dos pasos, ni "dar acceso" a tu cuenta. Todo el proceso ocurre en tu navegador; lo único que se comparte al final es una URL pública de recepción de datos (como el link del canal de WhatsApp que ya usa el sitio).
1

Crea la hoja de cálculo

Abre una Google Sheet nueva:

sheets.new →

En la fila 1, escribe estos encabezados, uno por columna:

Fecha · Nombre · Correo · Negocio · Telefono · Origen

Ponle un nombre a la hoja arriba a la izquierda, por ejemplo "CLARVO — Leads Masterclass".

2

Abre el editor de Apps Script

Desde esa misma hoja, en el menú superior:

Extensiones → Apps Script

Se abre una pestaña nueva con un editor de código, ya conectado a tu hoja.

3

Pega este código

Borra el contenido de ejemplo (function myFunction() {...}) y pega esto completo:

const CONFIG = {
  NOTIFY_EMAIL: "TU-CORREO-AQUI@ejemplo.com", // <-- cámbialo por tu correo real
};

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

    sheet.appendRow([
      data.fecha,
      data.nombre,
      data.correo,
      data.negocio,
      data.telefono,
      data.origen,
    ]);

    MailApp.sendEmail({
      to: CONFIG.NOTIFY_EMAIL,
      subject: "Nuevo registro — Masterclass CLARVO",
      body:
        "Nombre: " + data.nombre + "\n" +
        "Correo: " + data.correo + "\n" +
        "Negocio: " + data.negocio + "\n" +
        "Teléfono: " + data.telefono + "\n" +
        "Fecha: " + data.fecha,
    });

    return ContentService
      .createTextOutput(JSON.stringify({ ok: true }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: String(err) }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Edita la línea 2 (NOTIFY_EMAIL) con el correo real donde quieres recibir cada registro.

Guarda con Ctrl+S. Te pide nombre de proyecto — pon algo como "Leads Masterclass".

4

Publica como aplicación web

  1. Arriba a la derecha, botón azul Implementar → Nueva implementación.
  2. Junto a "Seleccionar tipo" (ícono de engrane ⚙️) → Aplicación web.
  3. Configura:
    • Ejecutar como: Yo (tu correo)
    • Quién tiene acceso: Cualquier usuario
  4. Clic en Implementar.
5

Autoriza el script (es tuyo, no mío)

Te pide iniciar sesión y autorizar permisos (Sheets + Gmail). Aparece una pantalla de advertencia tipo "Google no verificó esta app" — es normal en scripts personales no publicados:

  1. Clic en Configuración avanzada.
  2. Clic en Ir a "Leads Masterclass" (no seguro).
  3. Clic en Permitir.

Es tu script pidiéndote permiso a ti mismo — no le das acceso a nadie más.

6

Copia la URL

Al terminar aparece una URL de la aplicación web, termina en /exec. Cópiala completa y pásamela para conectar el formulario.

Si en el futuro editas el código

Publicar de nuevo con "Nueva implementación" te da una URL distinta. Para actualizar el código sin cambiar la URL: Implementar → Gestionar implementaciones → ✏️ (editar) → Versión: Nueva versión → Implementar.
